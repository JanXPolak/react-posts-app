# React Posts App

## What the project does

A web application for creating, viewing, and managing posts. It provides a clean, form-driven interface where users can add new posts and browse existing ones, with validation and instant feedback baked in.

## Technologies used

- **Next.js 16** – React framework (App Router) for routing, rendering, and server-side logic
- **React 19** – UI library
- **TypeScript** – static typing across the codebase
- **Tailwind CSS 4** – utility-first styling
- **Zod** – schema validation for forms and data
- **Sonner** – toast notifications for user feedback
- **ESLint** – code linting and consistency

## Project features

- Create and view posts through a simple, responsive UI
- Client-side form validation powered by Zod
- Real-time toast notifications for actions and errors
- Fully typed codebase with TypeScript for better reliability
- Built on the Next.js App Router for fast, modern routing
- Styled with Tailwind CSS for a consistent, utility-first design system

## Getting started

```bash
# install dependencies
npm install

# start the development server
npm run dev

# build for production
npm run build
npm run start
```

The app will be available at `http://localhost:3000`.
